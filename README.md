# Agent Skills

A collection of agent skills by [@brunodesde1987](https://github.com/brunodesde1987).

## JavaScript & TypeScript

- **modern-ecmascript** — Modern ES2023–ES2027 patterns based on TC39 official proposals. Replaces spread-sort, reduce-grouping, promise hoisting, and other outdated idioms with native equivalents.

  ```
  npx skills@latest add brunodesde1987/skills/modern-ecmascript
  ```

  To try it without installing:

  ```
  npx skills@latest use brunodesde1987/skills@modern-ecmascript
  ```

The `skills` CLI needs Node.js 22.20 or later.
